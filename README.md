# مساعد النورس الذكي | NAWRAS AI AGENT

واجهة عربية من اليمين إلى اليسار لمساعد عمليات أولي موجّه لسياق الشحن والتوصيل. يوفّر هذا الإصدار محادثة للمساعدة في الفهم والتحليل والتخطيط، ولا ينفّذ تغييرات على نظام النورس أو قاعدة البيانات.

## المتطلبات

- Node.js 20 أو أحدث وnpm.
- مشروع Supabase عند تفعيل المحادثة.
- مفتاح واحد على الأقل لمزوّد ذكاء اصطناعي، محفوظ في أسرار Supabase Edge Functions.

## التشغيل المحلي

```bash
npm install
cp .env.example .env.local
npm run dev
```

يمكن تشغيل الواجهة للمعاينة من دون إعداد Supabase. لا تعمل المحادثة حتى تضيف `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` إلى `.env.local`، وتنشر الدالة الخلفية وتوفّر جلسة مستخدم مصادقاً عليها. لا تضع مفاتيح المزودات أو `service_role` في متغيرات `VITE_` أو في ملفات المتصفح.

## النشر على GitHub Pages

يُنشر الموقع تلقائياً عند الدفع إلى الفرع `main` عبر `.github/workflows/deploy-pages.yml`. يحتوي workflow على رابط Supabase ومفتاح `sb_publishable_` عام مخصص للاستخدام من المتصفح؛ يمكن تعديلهما إذا تغير المشروع. لا تضع هنا مفتاح `service_role` أو مفاتيح مزودي الذكاء الاصطناعي. عنوان الموقع المتوقع: `https://aahhhjk99-pixel.github.io/NAWRAS-AI-AGENT/`.

إعداد بيانات العميل لا ينشئ حساب دخول ولا يفعّل المحادثة وحده. يلزم نشر دالة Supabase وضبط أصل GitHub Pages في CORS وإعداد مفتاح مزود ذكاء اصطناعي كسرّ خادمي، كما يلزم وجود جلسة مستخدم مصادق عليها؛ لا تتضمن هذه النسخة شاشة تسجيل الدخول بعد.

## نشر دالة المحادثة

اربط CLI بمشروع Supabase الذي تملكه أو لديك تفويض لإدارته. استخدم قيم مشروعك أنت؛ لا توجد قيمة مشروع افتراضية داخل المستودع.

```bash
supabase login
supabase link --project-ref YOUR_PROJECT_REF
supabase secrets set OPENAI_API_KEY=YOUR_KEY
supabase secrets set AI_DEFAULT_PROVIDER=openai
supabase secrets set ALLOWED_ORIGINS=https://YOUR_APP_ORIGIN
supabase functions deploy ai-chat
```

يمكن إضافة `GEMINI_API_KEY` أو `ANTHROPIC_API_KEY` كأسرار خادم لتفعيل التحويل الاحتياطي. يمكن ضبط اسم النموذج لكل مزوّد عبر `OPENAI_MODEL` و`GEMINI_MODEL` و`ANTHROPIC_MODEL`. تحقّق من أسماء النماذج المدعومة لدى المزود قبل النشر. لا تنفّذ أوامر الأسرار بمفاتيح حقيقية داخل سجل طرفية مشترك أو مستودع.

## البنية

- `src/`: واجهة React وTypeScript، والخدمات والأنواع المستخدمة في المتصفح.
- `supabase/functions/ai-chat/`: دالة خادمية لاستدعاء مزودي الذكاء الاصطناعي. الأسرار لا تغادر الخادم.
- `public/brand/`: صورة شعار مرجعية وأصول الهوية.
- `docs/`: معمارية النظام، قواعد الأمان، وإرشادات الهوية.
- `tests/`: اختبارات أولية وقائمة تحقق يدوية.

## حدود مهمة

- يتطلب استدعاء Edge Function جلسة Supabase صالحة. شاشة تسجيل الدخول وإدارة الموظفين غير مشمولة بعد.
- الدالة تقبل طلبات المصادق عليهم، لكن لا تتضمن حالياً تحديد معدل الاستخدام أو سقف تكلفة لكل مستخدم؛ لا تعرضها للإنتاج قبل إضافتهما.
- سياسات الأدوار والتدقيق والتسجيل الدائم للمحادثات غير مكتملة.
- تكامل نظام النورس مقصور على حالة تعريفية/معاينة. لا توجد أوامر دخول آلي أو عمليات قراءة/كتابة على النظام.
- إنشاء المهام غير مفعّل، ولا يجري المتصفح استعلاماً عن سجلات قاعدة البيانات.
- ألوان الواجهة مستوحاة من الشعار والصور العامة المنشورة، وليست دليلاً رسمياً كاملاً للعلامة. راجع `docs/BRAND_GUIDE.md`.

## قواعد أمان أساسية

- استخدم المفتاح العام Supabase في المتصفح فقط، ولا تمنح المتصفح صلاحية service role.
- احتفظ بمفاتيح مزودي الذكاء الاصطناعي في أسرار الخادم فقط.
- لا ترسل كلمات مرور أو رموز جلسات إلى المساعد.
- لا تنفّذ عمليات مالية أو حساسة أو حذفاً قبل توثيق الصلاحيات وموافقة بشرية وفحص مستقل للنتيجة.
- راجع سياسة الاحتفاظ بالرسائل ومشاركة البيانات مع مزودي الذكاء الاصطناعي قبل الاستخدام الفعلي.
