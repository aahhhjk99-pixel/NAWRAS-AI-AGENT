# إعداد مزودي الذكاء الاصطناعي

تعمل Edge Function المسماة `ai-chat` على الخادم، وتدعم حالياً ثلاثة مزودات: Gemini للتحليل، وGroq للردود السريعة، وOpenRouter لتجربة النماذج. تبقى مفاتيح المزودات في Supabase Edge Function Secrets ولا تُضمّن في ملفات الواجهة أو المستودع.

الأسرار المستخدمة هي `GEMINI_API_KEY` و`GROQ_API_KEY` و`OPENROUTER_API_KEY`. يمكن اختيار النموذج عبر `GEMINI_MODEL` أو `GROQ_MODEL` عند الحاجة؛ الافتراضيان الحاليان هما `gemini-flash-latest` و`llama-3.1-8b-instant`. يجلب التطبيق قائمة نماذج OpenRouter من الخادم، ويتحقق الخادم من أن النموذج المطلوب موجود في قائمته قبل إرسال الطلب.

تحتاج الدالة أيضاً إلى `AI_ALLOWED_EMAILS` لتحديد عناوين البريد المصرّح بها، وإلى `ALLOWED_ORIGINS` لقصر طلبات المتصفح على أصل الموقع، وإلى `AI_DEFAULT_PROVIDER` لاختيار المزود الافتراضي (`gemini` أو `groq` أو `openrouter`). في النشر عبر GitHub Pages يكون أصل المتصفح هو النطاق وحده، من دون مسار المستودع. تحفظ هذه القيم من خلال إدارة أسرار Supabase ولا تضع قيم المفاتيح أو عناوين الحسابات داخل Git.

لا تنتقل الدالة تلقائياً إلى مزود آخر عند فشل الطلب؛ يبقى المزود المختار كما هو، ويُعرض خطأ آمن إذا لم يكن مفتاحه مهيأ أو تعذر الطلب. يلزم الحصول على مفتاح Groq صالح قبل تفعيله. راجع كذلك حدود المعدل والتكلفة وسياسة الاحتفاظ بالبيانات قبل توسيع قائمة المستخدمين المصرح لهم.
