# معمارية التطبيق

## المسارات الرئيسية

- `src/App.tsx`: تركيب مساحة العمل وإظهار وضع التكامل.
- `src/components/`: عناصر الواجهة العربية، بما فيها القائمة والمحادثة وحالة الإعداد.
- `src/hooks/useChat.ts`: إدارة رسائل المحادثة وحالات التحميل والخطأ.
- `src/services/ai.ts`: استدعاء Supabase Edge Function من المتصفح.
- `src/services/integration.ts`: وصف حالة تكامل النورس؛ لا يرسل طلبات إلى النظام.
- `src/services/tasks.ts`: رفض آمن لإنشاء المهام إلى حين اعتماد المخطط والصلاحيات.
- `supabase/functions/ai-chat/index.ts`: تحقق الطلب، CORS، اختيار المزود، وإرجاع الرد.

## تدفق المحادثة

1. يكتب المستخدم رسالة في واجهة React.
2. يرسل المتصفح الرسائل إلى Edge Function عبر عميل Supabase ومفتاح عام.
3. تتحقق الدالة من جلسة Supabase وفق إعدادات Supabase، ومن أصل الطلب ومحتوى الرسائل.
4. تستخدم الدالة مفاتيح الخادم لاستدعاء المزود الأساسي، ثم المزودات البديلة المهيأة عند الحاجة.
5. يعود الرد من دون حفظ تلقائي للمحادثة في قاعدة البيانات.

## ما هو غير موجود بعد

لا توجد طبقة تسجيل دخول للمستخدمين، أو إدارة أدوار كاملة، أو سجل تدقيق، أو حدود استخدام وتكلفة، أو قاعدة بيانات محادثات. كما لا توجد واجهة تشغيل حقيقية داخل Backoffice النورس. يجب إكمال هذه الأجزاء ومراجعتها أمنياً قبل أي استخدام إنتاجي.
